# aauto.aar

Google's unofficial Android Auto SDK (`com.google.android.apps.auto.sdk`), taken
from the Fermata project (https://github.com/AndreyPavlenko/Fermata,
`fermata/lib/auto/aauto.aar`). Moonfin-Auto uses its `CarActivityService` /
`CarActivity` to draw the full app on the Android Auto screen. See
`org/moonfin/androidtv/car/`.
